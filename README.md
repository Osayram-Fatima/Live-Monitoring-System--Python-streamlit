 **Live-PC-Monitor — Premium Streamlit Dashboard**

A real-time System Performance & Health Monitor built with Python. This project goes beyond basic utility, featuring a custom-styled, premium CSS dashboard for a high-end SaaS feel. Track CPU, RAM, and Disk health with live updates through a clean, modern web interface.

**How to get started:**
Install Streamlit:
     _pip install streamlit_
     
Run the App:
    _streamlit run app.py_
